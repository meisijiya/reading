# additions/ — 知识包增量区

本目录存放你后续产生的新理解、新案例、实践结果。**不要修改 `00-原书档案/` 与 `NN-*/` 模块 README（它们是证据层）**，新内容一律追加到这里。

## 命名规范

```
YYYY-MM-DD-主题.md        例：2026-08-25-拆分订单单体实践.md
```

## 记录模板

```markdown
# <标题>

- 日期：YYYY-MM-DD
- 类型：新理解 | 新案例 | 实践结果 | 修正
- 关联：章节锚点（如 §2.2.1 信息隐藏）或速查表条目

## 内容

<你的理解 / 案例经过与结果 / 实践中的做法>

## 对知识包的影响

<是否推翻或细化了某条既有规则？指出文件与条目，如「99-速查表.md → 服务边界划分（§2.2）」>
```

## 维护约定

1. **冲突处理**：若新认知与原书规则冲突，在 additions 文件里写明理由即可，不回改原文层——保留演化历史。
2. **检索**：AI 使用本包时应把 `additions/*.md` 与 `99-速查表.md` 同优先级纳入检索，additions 中标注"影响"的新条目视为对速查表的覆盖更新。
3. **升级全文**：本包全文已 100% 落档（epub 一次性提取，16 章 + 157 小节 + 282 子小节 + 227 图），无升级需要；若日后原书修订版发行，重新解析 epub 覆盖 `00-原书档案/fulltext/` 即可。
