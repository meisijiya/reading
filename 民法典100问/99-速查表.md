## 一、生活场景 → 法律规则速查

### 婚姻·家庭
| 场景 | 规则 | 出处 |
|---|---|---|
| 要彩礼才结婚 | 彩礼属赠与、合法；"禁止借婚姻索取财物"仅倡导性规定无罚则；领证后借彩礼钱用于共同生活可能成共同债务 | Q50 |
| 离婚时退彩礼 | 仅三种情形退：①未办结婚登记②登记但确未共同生活③婚前给付致生活困难（②③以离婚为条件） | Q52 |
| "忠诚协议" | 法律不禁止但**无强制力**；约定必须离婚/抚养权归属/剥夺探视权等**人身关系条款无效** | Q51 |
| 配偶隐瞒重大疾病 | 可申请撤销婚姻（2003年10月起婚前体检不再强制） | Q53 |
| 全职太太离婚 | 无特别约定时可平分共同财产 + 家务补偿款（《民法典》第1088条，案例判5万元）；补偿不按家政工资标准算 | Q54 |
| 妻子擅自打胎 | 不侵犯丈夫生育权——女性生命健康权 > 男方配偶权性质的生育权；怀孕期间/分娩后1年内/终止妊娠后6个月内男方不得提离婚 | Q55 |
| 婚前全款房的租金 | 无需管理维护（清水房、租客负责装修维护）→孳息=个人财产；付出经营管理→经营性收益=共同财产 | Q56 |
| 夫妻间打借条 | 书面形式+非个人财产出借→视为财产约定，合法有效须还；借款若用于家庭开支则转化为共同债务 | Q57 |
| 一方婚内转移财产 | 另一方可诉请婚内分割共同财产（《民法典》第1066条：隐藏/转移/变卖/毁损/挥霍/伪造共同债务） | Q58 |
| 签"断绝父子关系"协议 | 血缘关系无法断绝；抚养赡养义务是强制性的——"权利可以放弃，义务却不能"；子女赡养不以父母尽过抚养义务为前提 | Q59 |
| 大学生要抚养费 | 年满18周岁即无权要求；父母资助属自愿赠与 | Q60 |
| 成年姐姐必须养弟弟吗 | 有负担能力的兄姐对"父母死亡或无力抚养的未成年弟妹"有扶养义务（注意用字："扶养"非"抚养"，第1075条）；受扶养长大的弟妹对缺乏劳动能力又缺乏生活来源的兄姐有反哺义务 | Q61 |
| 继子赡养继父 | 受继父抚养教育的继子女有赡养义务；父/母不得擅自改子女姓氏为继母/继父姓，纠纷应责令恢复原姓氏 | Q62 |
| 离婚流程时长 | 协议离婚：申请→30天冷静期（任一方可单人撤回）→再30天内领证，最快31天，共31-60天窗口；对方拖延离不成→只能诉讼离婚 | Q63 |
| 法院判离婚条件 | 重婚或与他人同居；家暴或虐待遗弃家庭成员；赌博吸毒屡教不改；感情不和分居满2年；一方被宣告失踪；判不准离婚后又分居满1年再次起诉 | Q64 |
| 孩子抚养权 | <2周岁随母为原则；已满2周岁按最有利于未成年子女原则判；已满8周岁尊重其真实意愿 | Q65 |
| 出轨能让他净身出户吗 | 不能。偶尔开房≠"与他人同居"（须以夫妻名义长期持续共同生活）；法定过错赔偿仅五种：重婚/与他人同居/家暴/虐待遗弃/其他重大过错；出轨对共同财产分割一般无影响；起诉离婚时未提赔偿法院不主动判；曾明确放弃赔偿后再诉不支持 | Q68 |
| 收养条件 | 成年人不能被收养；无配偶者收养异性子女须年龄相差40周岁以上 | Q69 |
| 收养后亲生父母能要回吗 | 收养关系成立即消除生父母及近亲属的权利义务关系（第1111条） | Q70 |

### 财产·房产·借贷
| 场景 | 规则 | 出处 |
|---|---|---|
| 买房只签合同没过户 | 房子还不一定是你的——不动产所有权转让以登记生效；签合同至过户间隙风险最大；新房可办**预告登记**锁死产权；二手房无法预告登记，须查共有权人同意/抵押/债务；一房多卖中已过户者得房，你只能追究违约责任 | Q16, Q30 |
| 房东卖房与租客 | 房东卖房无须租客同意但须提前合理期限通知；租客享同等条件优先购买权（第726条），被侵害可索赔实际损失；买卖不破租赁 | Q37 |
| 过户给子女后养老 | 办**居住权**：书面合同+不动产登记领证；期限内对抗所有权变更/买卖/继承/抵押；原则不可出租（可另行约定） | Q23 |
| 欠钱不还扣车抵债 | ❌不能私自扣车。抵押=物在债务人手上，质押=物交债主手上；均须书面合同载明担保债权/期限/财物/范围；正确路径=起诉+申请强制执行 | Q25 |
| 借钱没写借条 | 合同形式灵活（微信记录/转账备注"借款"+金额+双方姓名也是证据）；只有借条没有支付凭证不易胜诉；催债起诉趁早防3年时效 | Q26, Q36 |
| 给人做担保 | 债务转移未经担保人**书面同意**→担保人对转移部分免责；连带担保=别人还不起你还；担保是高风险行为三思而行 | Q24 |
| 捡到东西索要报酬 | 必要费用（电话费/邮费/交通费/保管中实际损失）可要求失主支付，超出部分无权索要；拒不归还轻则拘留罚款，重则侵占罪最高5年；招领公告满1年无人认领归国家 | Q8 |
| 项链被拾得人卖了 | 权利人有权要回（遗失物不适用善意取得）；若买家经拍卖或有资质商家购得，要回须先垫付买家价款再向无处分权人追偿；若是**借用物被友私自卖掉**且买家不知情+支付合理价格→善意取得成立，只能找朋友赔 | Q20 |
| 农村宅基地继承 | 地（集体所有）不能被继承，房和附属设施可继承；城镇户籍子女可凭继承办理不动产登记；已分户另有一宅者受"一户一宅"限制；房屋塌陷失修后村集体可收回宅基地；国家允许自愿有偿退出 | Q22 |
| 耕地互换补偿 | 承包经营权互换/转让须经登记才有对抗效力（第335条）；互换=还持有承包权，转让=彻底丧失 | Q21 |
| 小区物业 | 不用电梯也须交物业费——共有部分权利义务不得放弃；物业**不得停水停电停气催费**；服务不达标（按合同约定而非主观感受）可要求减免；电梯广告收益归全体业主 | Q17 |
| 邻居噪音 | 昼间(6:00-22:00)≤55分贝，夜间(22:00-6:00)≤45分贝；治安处罚警告不改罚200-500元；可诉请赔偿损失+停止侵害 | Q18 |
| 商家标错价拒发货 | 真标错价=重大误解，但撤销须经法院/仲裁程序，且须退款+赔偿消费者损失；故意低价引流后砍单=违约，消费者可要求按标价发货 | Q9 |
| 预订酒店"不可退费" | "贵重物品自行保管，遗失概不负责""受伤责任自负"等格式条款一律无效 | Q29, Q39 |
| 合同只签了一方名字 | 一方已履行主要义务且对方接受→合同照样成立（第490条） | Q30 |
| 培训机构跑路 | 不是诈骗（无"非法占有目的"证据）→走民事：公司工商登记跑不了，起诉+清算还债路径可行；民事起诉**没有金额门槛**，索赔1元也受理；预防>维权：别一次预交大额学费 | Q31 |
| 假离婚逃债 | 无偿处分财产/明显不合理价格转让（低于市场价70%或高于30%）影响债权人实现的，债权人可请求法院撤销 | Q32 |
| 商家提前发货 | 债权人可以拒绝提前履行（第530条）；提前履行增加的费用由债务人承担；收下则视为同意 | Q33 |
| 快递放柜丢失 | 消费者与快递公司**无合同关系**→找商家（要求送货上门或协商赔偿），勿直接与快递扯皮；也可向邮政管理部门投诉举报 | Q34 |
| 捐款反悔 | 未签合同未公开承诺→可不捐；已捐出→所有权已转移原则上不能要回；看两点：①所有权是否转移②是否特殊赠与（公益慈善/道德义务性质不可任意撤销➕） | Q35 |
| 跳过中介成交 | 绕开中介私下成交，**或换另一家中介**成交，都要付中介费（禁止"跳单"） | Q40 |
| 吃霸王餐 | 店主不能扣人，但可自助扣留与餐费等值的随身财物，且须立即报警/起诉处理；付了钱须退还 | Q85 |

### 人格权·名誉·隐私
| 场景 | 规则 | 出处 |
|---|---|---|
| 职场性骚扰 | 《民法典》首次定义：违背他人意愿+言语/文字/图像/肢体等与性有关的骚扰；受害者不限性别（判断标准是相对人是否排斥抗拒）；固定证据→单位投诉→报警/起诉 | Q41 |
| 死者器官捐献 | 本人生前书面同意有效（口头无效）；生前未表示不同意→死后配偶+成年子女+父母**共同决定**可捐；生前明确反对则家属无权；器官只能无偿捐献禁止买卖 | Q42 |
| 单亲妈妈给孩子改姓 | 可以协商变更；但父/母擅自改随继父继母姓的应责令恢复；"不违背公序良俗的其他正当理由"可申请 | Q43, Q62 |
| 肖像权范围 | 不限于面部——任何可识别特定人的外部形象（体态、手等）都受保护 | Q44 |
| 被朋友圈骂 | 取证方式：公证或手机录屏完整展示个人信息+内容；可诉请赔礼道歉（当面/书面/登报/发朋友圈）+精神损害赔偿（案例判2万）；未核实就传播"某人是罪犯"致社会评价降低也算侵权 | Q45 |
| 曝光婚外情 | 三条底线：陈述事实不编造+信息合理核实+不骂人→一般不侵权；自己合法获取的婚外情证据只能用于诉讼，随意扩散=侵犯隐私；对方公共场所暴露行踪的不属隐私；法律保护其人格权≠纵容婚外情 | Q46 |
| 经历被改编成电影 | 以特定人为描述对象须授权；作品不以特定人为描述对象、仅情节相似→不担责（第1027条第2款） | Q47 |
| 征信记错 | 可诉银行停止侵害+消除记录+赔偿（案例：消除记录+精神抚慰金3000元）；不良信用记录保存期限5年，超期应删除 | Q48 |
| 强制人脸识别入园 | 个人信息收集须合法正当必要；过度收集/强制刷脸现象普遍，注意保护意识（原书此问原文数据少） | Q49 |

### 侵权·赔偿
| 场景 | 场景细分 | 规则 | 出处 |
|---|---|---|---|
| 被打还手 | 时机 | 必须不法侵害**正在进行**时还手才算正当防卫；事后报复="秋后算账"违法；来不及还手就报警/起诉 | Q13 |
| 被打还手 | 限度 | 明显超过必要限度造成不应有伤害=防卫过当，承担部分民事责任；推一下就动刀砍重伤=过当 | Q13 |
| 正当防卫后果 | 免责范围 | 未超限度的正当防卫刑事+民事都不担责（第181条）；对行凶杀人抢劫强奸绑架等严重暴力犯罪防卫即使致死也不担刑责 | Q13 |
| 救火淹了楼下 | — | 紧急避险：险情由他人引起（雷击等）→避险人不担责，受益人可适当补偿；险情由自己引起→自己担责；针对无辜第三方的牺牲 smaller interest 制度 | Q14 |
| 打官司过期 | — | 诉讼时效普通3年（自知权利受损及义务人之日），最长20年；未成年遭性侵的时效自年满18周岁起算；躺在权利上睡觉=败诉 | Q15 |
| 借条时效 | — | 约定还款日起3年内不主张→对方可提时效抗辩；每次有效催讨**重新计算**3年 | Q36 |
| 熊孩子闯祸 | — | 8岁以下无行为能力人；8-18岁限制行为能力人；16岁以上以劳动收入为主要来源视为完全；监护人担责（学校管理有漏洞且不能自证清白的也要担） | Q83 |
| 运动受伤 | — | 自甘风险：自愿参加有一定风险的文体活动，被其他参加者行为致害→不得请求其他参加者担责 | Q84 |
| 宠物伤人/死亡 | 撸猫被咬 | 未拴绳/戴嘴套/关门等安全措施不到位→饲养人不能免责（案例：80%/20%分担） | Q96 |
| 宠物伤人/死亡 | 喂流浪狗 | 长期固定喂养=形成喂养事实→未采取安全措施控制，咬伤人要赔偿；一次性投喂不算 | Q97 |
| 宠物被弄死 | — | 按死亡时市场价格或其他合理方式赔；饲养成本投入与价值提升无因果关系；精神损失费一般不高（案例3000元） | Q86 |
| 醉酒闯祸 | — | 醉酒者自己担全责；同饮者中劝酒的、未尽安全保障注意义务的按比例担责 | Q87 |
| 装修工人摔伤 | — | 层层转包链条按选任过错比例分担（案例：房主10%/承包者20%/包工头50%/工人自负20%）；专业人选任过错大于普通人 | Q88 |
| 游乐场孩子受伤 | — | 直接侵权人担主要（案例60%）+场所方安保义务（20%）+监护人疏忽自担（20%） | Q89 |
| 借车出事故 | — | 使用人担责；车主明知车有隐患或借给无资质者有过错→承担相应责任；车被偷开同理 | Q90 |
| 肇事逃逸 | — | 赔付顺序：交强险限额内→商业三者险按合同→仍不足由侵权人赔 | Q91 |
| 好意同乘 | — | 无偿搭便车出事故，驾驶人有过错仍担责但**应减轻**（好意施惠价值导向）；注意交强险不赔本车人员 | Q92 |
| 商品质量问题 | — | "签收概不负责"声明违法；机动车/家电等耐用商品及装饰装修服务6个月内质量争议由商家厂家**举证责任倒置**；可直接找商家或厂家任一索赔 | Q93 |
| 手术签字僵局 | — | 紧急情况下无法征求家属意见→经医疗机构负责人批准可立即手术；医院存在故意或重大过失、未尽与当时医疗水平相应义务仍担责 | Q94 |
| 医院不给病历 | — | 医院隐匿/拒绝提供病历要承担责任（原文数据少） | Q95 |
| 广告牌砸人 | — | 建筑物搁置物脱落坠落：所有人/管理人/使用人**不能证明自己没过错**就要赔（过错推定） | Q98, Q100 |
| 高空抛物找不到人 | — | 可能加害的使用人**共同补偿**+物业公司（未尽安保义务）分担；事后找到真凶可向其追偿；抛物致人死亡最高可涉过失致人死亡罪7年（案例：25户业主+物业共赔30万医疗费）；先报警，警方调查结果=起诉有力证据 | Q99 |
| 行道树砸车 | — | 谁管理谁举证：管理部门不能证明自己无过错则担责；纯不可抗力则所有人管理人不担责 | Q100 |

### 民法基础
| 场景 | 规则 | 出处 |
|---|---|---|
| 胎儿获赠财产 | 涉及遗产继承、接受赠与等胎儿利益保护→胎儿视为具有民事权利能力；娩出为死体的权利能力**自始不存在**（赠与无效，财产按其他继承人份额处理） | Q2 |
| 撤销监护资格 | 两种法定情形：①严重损害被监护人身心健康②怠于履职致其处于危困状态+其他严重侵害行为；被撤销仍须继续付抚养费；确有悔改可恢复，恢复则法院指定监护关系终止；无人监护时民政部门兜底 | Q3 |
| 孩子打赏主播 | 8-18岁限制行为能力人：大额打赏效力待定，未经父母同意/追认无效可主张返还；但家长须证明操作时点+事先不同意，且有管护过错则按比例分担（案例：法院判部分退还）；根治办法=管好支付密码 | Q4 |
| 宣告失踪配偶改嫁 | 下落不明满4年/意外事件满2年/意外+机关证明不可能生存（无时限）→利害关系人可申请宣告死亡；公告期1年（证明不可能生存的3个月）；判决作出之日=法律死亡日期；宣告死亡后婚姻自动解除，撤销宣告后：配偶未再婚自行恢复/已再婚或书面声明不愿恢复则不复原 | Q5 |
| 丈夫欠债妻子还吗 | 共同生产经营或收益用于家庭→共同债务连带责任；无法区分个人/家庭经营→以家庭财产承担；婚前个人经营且收入未入家→个人债务；夫妻对外是整体，内部追偿离婚时算账 | Q6 |
| 当法人的风险 | 公司有限责任以全部财产独立担责，但法定代表人会被连带走限制高消费；公司犯罪时直接主管人员可能被判刑；所以有人投资当股东却不当法人 | Q7 |

## 三、《民法典》九部废止整合法律（📖原文）

2021年1月1日民法典生效同时废止：《婚姻法》《继承法》《民法通则》《收养法》《担保法》《合同法》《物权法》《侵权责任法》《民法总则》。

## 四、继承与遗嘱核心规则

- **效力顺位**：遗赠扶养协议 > 遗嘱 > 法定继承 —— Q71
- **遗嘱六形式**：自书、代书、打印、录音录像、口头、公证（第1134-1139条）—— Q77
- **打印遗嘱要件**：每页均有立遗嘱人和见证人亲笔签名，见证人须2名以上—— Q77
- **见证人定义**：在遗嘱上签字作证者；仅在场未签字不算—— Q76
- **多份遗嘱**：内容抵触时**以最后一份为准**，公证遗嘱不再有优先效力—— Q78
- **篡改遗嘱**：篡改部分无效，不影响其余部分效力—— Q79
- **丧失继承权**：虐待父母情节严重等（确有悔改且被宽恕可不丧失➕）—— Q72
- **继承权扩张**：非婚生子女、养子女、有扶养关系的继子女同权；侄甥代位继承为新规—— Q73
- **限定继承**：父债子偿以遗产实际价值为限，超出部分自愿否则免；放弃继承即免责—— Q82
- **法定继承所得**属夫妻共同财产（无特别约定时）—— Q74
