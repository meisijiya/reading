# additions/ — 知识包增量区

本目录存放你后续产生的新理解、新案例、实践结果。**不要修改 `01~07` 的原文档案**（它们是证据层），新内容一律追加到这里。

## 命名规范

```
YYYY-MM-DD-主题.md        例：2026-08-23-租房纠纷实战.md
```

## 记录模板

```markdown
# <标题>

- 日期：YYYY-MM-DD
- 类型：新理解 | 新案例 | 实践结果 | 修正
- 关联：Q编号（如 Q65）或速查表条目

## 内容

<你的理解 / 案例经过与结果 / 实践中的做法>

## 对知识包的影响

<是否推翻或细化了某条既有规则？指出文件与条目，如「99-速查表.md → 抚养权（Q65）」>
```

## 维护约定

1. **冲突处理**：若新认知与原书规则冲突，在 additions 文件里写明理由即可，不回改原文层——保留演化历史。
2. **检索**：AI 使用本包时应把 `additions/*.md` 与 `99-速查表.md` 同优先级纳入检索，additions 中标注"影响"的新规则视为对速查表的覆盖更新。
3. **升级全文**：若获得全书正文，放入 `00-原书档案/fulltext/` 并按章节分文件命名 `uid-XX-题名.md`。
