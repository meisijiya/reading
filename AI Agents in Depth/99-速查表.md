## 二、决策框架（选 A 还是 B）

| 决策点 | 选择 | 查 Q 编号 |
|---|---|---|

| 工具粒度整合还是独立？ | 功能相似 + 场景重叠 → 整合；参数差异大/高频 → 独立 | Q4-3 |
| 状态栏实现：替换 vs 持久追加？ | 状态大/更新频繁/轨迹长 → 替换；状态小/新增多/受控 → 持久追加 | Q2-10 |
| 上下文压缩时机？ | 接近窗口阈值时批量压缩（不每轮压） | Q2-12 |
| 隔离 vs 压缩？ | 独立子任务 → 子 Agent 隔离 | Q2-13 |
| 评估 Pass@k vs Pass^k？ | 探索/创作 → Pass@k；生产/支付 → Pass^k | Q6-2 |
| SFT vs RL 先后？ | 小模型 + 严格结构化 → 必须先 SFT；强基模 + 容忍瑕疵 → 可直接 RL | Q7-3 |
| 模型替换实验 vs 消融实验？ | 区分瓶颈在模型还是在 Harness → 换模型；定位 Harness 内部组件 → 消融 | Q6-1 |
| 共享 vs 不共享上下文？ | 角色差异主要是知识/流程/风格 → Skill；涉及权限/合规/硬禁止 → transfer_to_agent | Q10-3 |
| 多 Agent vs 单 Agent？ | 引入新信息（执行/视觉/工具反馈）→ 多 Agent 显著提升；只辩论同一段文本 → 持平 | Q10-2 |

## 三、安全与防御（红线）

| 威胁 | 防御层 | 查 Q 编号 |
