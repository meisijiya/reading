# 引言与后记

> 引言（ch001）讲"为什么写这本书 + 怎么读"，后记（ch012）回到核心公式的延伸。本模块不抽问答卡片，仅作为"读前 / 读后"导航。

## 引言核心信息（ch001）

- **作者立场**：李博杰（Pine AI 首席科学家），从 2025 年图灵《AI Agent 实战营》讲座和实验整理而来
- **核心公式贯穿全书**：`Agent = LLM + 上下文 + 工具`
- **写作方法**：用 Pine 自己的语音 Agent 做"口述-调研-讨论-修改"循环（whisper coding）——本书**也是由 Agent 参与做成的作品**
- **核心论断**：
  - " **实践在前，命名在后** "——Skill、harness、loop engineering 等概念都是 Agent 早就在做，Anthropic 等公司才提炼命名
  - " **这些原则非但没有过时，反而变得越来越经典了** "
- **学习建议**：
  - 章节相对独立——Agent 开发者按顺序读第一至八章
  - 时间有限——优先读第一章（全局认知）+ 第二章（最关键的上下文工程）
  - 关注模型训练——直接读第七章（模型后训练），第六（评估）是前提

## 关键术语约定（ch001）

- **思考（reasoning）** vs **推理（inference）**——本书刻意区分：
  - "思考" = 模型的内部推导（CoT、思考模型、思考 token、思考过程）
  - "推理" = 模型运行部署（推理时、推理成本、推理栈、推理时扩展）
  - 例外：逻辑推理、多跳推理、空间推理、时序推理——保留"推理"日常用法
- 关键术语在首次出现处给中英文对照

## 后记核心信息（ch012）

- **回到核心公式**：`Agent = LLM + 上下文 + 工具`——全书十章都围绕这三个词展开
- **两朵乌云**：
  - 模型自主空间越大，Harness 越需要兜底（呼应 Q1-3 "模型即 Agent" + Q1-6 Harness 五大功能）
  - 多 Agent 协作的群体智能可超越个体总和（呼应 Q10-1 多 Agent 分类框架）
- **模型与 Agent 的共同演进**：模型越强 → Harness 越简单 → 但边缘场景（高风险/小众）Harness 仍是关键
