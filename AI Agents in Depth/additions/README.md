# Additions 增量区

> 存放你对《深入理解 AI Agent：设计原理与工程实践》后续的新理解、新案例、新实践。

## 约定

- 每条新内容单独一个文件，命名：`YYYY-MM-DD-主题.md`
- 不修改 `00-原书档案/` 任何文件（那是机器可读原始数据）
- 与既有 `NN-模块/README.md` 冲突时，在本文件里写明理由并保留演化历史
- AI 检索时 `additions/` 与 `99-速查表.md` 同优先级；标注了"**影响**"的条目覆盖速查表对应旧条目

## 模板

```markdown
<!-- YYYY-MM-DD · 主题 · 作者 -->

## 背景

（你从哪个项目/案例/经验触发？）

## 新理解

（与书中原文的差异、补充或更新。引用卡片用 Q编号 链接到对应模块）

## 影响

（如有：影响 99-速查表 中哪条规则？影响哪个模块的哪个 Q？）
```
