# Appendix C: Prompt Engineering Tools

## Chat Interfaces

- ChatGPT — OpenAI’s chatbot, custom GPTs, image generation, Projects.
- Claude.ai — Anthropic’s chatbot, Artifacts, Projects, MCP connectors.
- Gemini — Google’s chatbot, Workspace integration, Gems.
- Grok — xAI’s chatbot with real-time X access.
- Perplexity — Research-focused, cites sources.
- Poe — Multi-model aggregator.

## Developer Frameworks

- LangChain — Python/JS framework for building LLM applications, chains, agents, RAG.
- LlamaIndex — Data framework for LLM apps, especially RAG.
- DSPy — Programming, not prompting — compile prompts from examples.
- OpenAI SDK / Anthropic SDK / Google GenAI SDK — First-party client libraries.
- Vercel AI SDK — Stream responses in Next.js / React.
- Instructor — Structured output via Pydantic for OpenAI/Anthropic.

## Evaluation & Observability

- LangSmith — Trace, evaluate, monitor LLM apps.
- Braintrust — Evaluation-first LLM ops platform.
- Helicone — Observability and cost tracking.
- PromptFoo — Command-line prompt evaluation.

## RAG and Vector Stores

- Pinecone, Weaviate, Qdrant, Chroma, Milvus — Vector databases.
- pgvector — Postgres extension for embeddings.
- LanceDB — Embedded vector DB.

## Automation Platforms

- Zapier — No-code automation with AI actions.
- Make.com — Visual automation builder.
- n8n — Open-source Zapier alternative.
- Pipedream — Developer-friendly workflows.

## Prompt Libraries

- PromptHero, PromptBase — Share and discover prompts.
- LearnPrompting.org — Free comprehensive course.
- Anthropic Prompt Library — Curated examples for Claude.
- OpenAI Cookbook — Code-heavy recipes.

## Local and Open-Source

- Ollama — One-command local model server.
- llama.cpp — Run Llama family models on CPU/GPU.
- LM Studio — Desktop UI for local models.
- vLLM — High-throughput server for production.
