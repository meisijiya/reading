## 三、常见陷阱（速查）

| 陷阱 | 说明 | 卡 |
|---|---|---|
| **悄悄丢信息** | 生产系统做摘要压缩可以，但**不能悄悄丢掉决定下一步行动所需的信息** | Q2-1 / Q2-18 |
| **改前缀毁缓存** | 改静态前缀会让后面全部缓存失效 | Q2-4 |
| **逐请求动态检索 Few-shot** | 会破坏前缀稳定性 | Q2-11 |
| **动作成功 ≠ 任务成功** | 经验写成程序时的经典陷阱 | Q8-6 |
| **保存经历 ≠ 从经历学习** | 需要三层轨迹验证 + Rubric | Q8-1 / Q8-2 |
| **只存不整理** | 知识更新必须同时有增量更新与定期整理 | Q3-16 |
| **观测泄露** | 评估时让 Agent 看到本不该看的信息，会虚高分数 | Q2-7 / Q6-7 |
| **只用 Pass@k 汇报** | 它只证明"原则上做得到"，业务要的是 Pass^k | Q6-2 |
| **省掉的成本相加** | 各项优化收益不可直接相加 | Q6-12 |
| **动态生成代码高权限运行** | 沙盒与命令安全校验不能省 | Q5-10 |

## 四、全书核心公式（速记）

```
Agent = LLM（大语言模型）+ 上下文 + 工具
Agent 上下文 = 静态前缀（系统提示词 + 工具定义）+ 轨迹（动态消息历史）
上下文五组件 = 系统提示词 · 工具定义 · 用户消息 · 模型回复 · 工具执行结果
```

三式的展开与三层含义（工程 / 直觉 / 学术映射）见 [Q0-1](00-引言与后记/README.md) 与 [Q1-1](01-AI-Agent入门/README.md)。
