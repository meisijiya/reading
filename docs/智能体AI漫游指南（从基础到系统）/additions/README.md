# Additions 增量区

> 存放你对《智能体 AI 漫游指南：从基础到系统》后续的新理解、新案例、新实践。

## 约定

- 每条新内容单独一个文件，命名：`YYYY-MM-DD-主题.md`
- 不修改 `00-原书档案/` 任何文件（那是机器可读原始数据，PDF 文本层逐字抽取，改了会破坏验证链）
- 与既有 `NN-模块/README.md` 冲突时，在本文件里写明理由并保留演化历史
- AI 检索时 `additions/` 与 `99-速查表.md` 同优先级；标注了"**影响**"的条目覆盖速查表对应旧条目

## 三级标记在本区的用法

沿用全包约定：📖原文＝回到 `00-原书档案/fulltext/chNN.md` 逐字引用｜🧭归纳＝你的提炼｜➕补充＝依据公开常识的编者视角。
本区新增内容默认属于 🧭 或 ➕，**只有回原文核对过的引用才能标 📖**。

## 本书原文的已知抽取限制（写卡片时注意）

- **公式**：来自 PDF 文本层，LaTeX 排版结构大多丢失（公式、变量名、公式编号常挤在一行）。回原文引用公式所在段落时，优先引解释性文字；重写公式请注明"据原文公式整理"。
- **图**：`00-原书档案/fulltext/chNN.md` 里 `*（[图片 · 原书 PDF pNNN]…）*` 表示该处有图，**图形本身未提取**，图内文字可能散落在附近正文行里。判断图文关系时以原书 PDF 页码为准。
- **表格**：按行提取，跨列关系以原书为准。
