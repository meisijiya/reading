# 导读与前置

> 本模块是全书的导航页：作者为什么写这本指南、2026 年的技术全景、目标读者与前置假设、全书六部分的组织方式、三条设计哲学、有意排除的范围、v1.3 版的新增主题，以及通往智能体 AI 的十年简史。它不承载技术结论，只解释这本书的取舍与读法。

## Q0-1 这本指南要解决什么问题？

- 章节: ch00 §前言·为什么要写这本指南　（原文：[ch00](../00-原书档案/fulltext/ch00.md)）
- 主题: 全书存在理由

> 📖 **原文** (ch00 §前言·为什么要写这本指南)：在2026年构建智能AI系统，需要掌握极其广阔的知识——从Transformer在内部如何处理语言，到使训练成为可能的硬件与系统，再到让训练高效的优化技术、教会模型推理并与人类意图对齐的强化学习算法，乃至大规模协调自主系统的多智能体架构。

> 📖 **原文** (ch00 §前言·为什么要写这本指南)：本指南之所以存在，是因为从业者需要一份覆盖整套技术栈的统一参考——不仅是理论，更是让事情真正跑起来的实现细节。

🧭 **归纳**：
- 作者判断当前缺口不是「某个知识点缺失」，而是「整条技术栈缺乏统一参考」。
- 该技术栈的跨度：从 Transformer 内部机制 → 硬件与系统 → 训练优化 → RL 对齐 → 多智能体架构。
- 对参考书的要求被明确为双标准：既讲理论，也讲让系统真正跑起来的实现细节。
- 同一逻辑贯穿全书设计：后文每一章都同时给公式、给代码/超参、给调试策略（见 Q0-5）。

## Q0-2 2026 年的全景分哪几个阶段？每个阶段的代表技术是什么？

- 章节: ch00 §前言·2026年的全景　（原文：[ch00](../00-原书档案/fulltext/ch00.md)）
- 主题: 技术全景四阶段

> 📖 **原文** (ch00 §前言·2026年的全景)：通向今天智能体AI系统的旅程，横跨三十年间在架构、训练与部署上不断累积的突破：

> 📖 **原文** (ch00 §前言·2026年的全景)：2.系统与效率（2020–2023）：FlashAttention [ 65 ] 通过消除显存瓶颈让训练加速2–4 ×。LoRA [ 147 ]让在单个节点上微调70B+模型成为可能。专家混合（Mixture-of-Experts, MoE）将模型容量与算力成本解耦。vLLM这类推理引擎把吞吐量带到了实时应用可触及的范围。

> 📖 **原文** (ch00 §前言·2026年的全景)：4.推理与自主（2024–2026）：DeepSeek-R1 [ 72 ]与OpenAI的o1/o3证明：RL可以教会模型推理本身——模型自发地发现思维链（Chain-of-Thought，CoT）、回溯与自我验证。与此同时，Model Context Protocol (MCP)统一了工具访问、智能体到智能体（Agent-to-Agent, A2A）使智能体间通信成为可能，生产级编排框架也走向成熟。

🧭 **归纳**：作者把 2026 年的智能体 AI 归到四个累积阶段，这四条线正好对应本书六部分中的主干：

| 阶段 | 时间 | 关键代表 | 解决的问题 |
|---|---|---|---|
| 1 架构基础 | 2017–2020 | Transformer self-attention、Scaling Laws、GPT-2/3 | 能力从哪里来（规模带来 few-shot 涌现） |
| 2 系统与效率 | 2020–2023 | FlashAttention、LoRA、MoE、vLLM | 训练/推理能不能负担得起 |
| 3 基于 RL 的对齐 | 2022–2024 | RLHF、DPO 及 KTO/IPO/ORPO/GRPO 变体 | 有能力但不实用的 base 模型怎么变成助手 |
| 4 推理与自主 | 2024–2026 | DeepSeek-R1、o1/o3、MCP、A2A | 怎么让模型自己推理、自己调用工具、自己协作 |

➕ **补充**：这张表同时是本知识库分片的坐标系——阶段 1/2/3 分别对应本模块 Q1-1 至 Q1-33（架构与优化）、Q1-34 至 Q1-39（系统基础）与 Q1-40 至 Q1-45（RL 导论）。

## Q0-3 谁该读这本书？需要什么前置知识？

- 章节: ch00 §前言·本指南的目标读者　（原文：[ch00](../00-原书档案/fulltext/ch00.md)）
- 主题: 目标读者与前置假设

> 📖 **原文** (ch00 §前言·本指南的目标读者)：本文档是为真正动手做东西的从业者而写：

> 📖 **原文** (ch00 §前言·本指南的目标读者)：•Agent开发者：构建生产系统，需要编排模式、记忆架构、工具集成（MCP）以及多智能体协作（A2A）。

> 📖 **原文** (ch00 §前言·本指南的目标读者)：我们假设读者熟悉神经网络与基础概率论。不要求事先具备LLM、RL或系统方面的知识——本指南从第一原理构建。

🧭 **归纳**：五类读者与各自要取的部分：
- ML 工程师：Transformer 内部机制、训练基础设施、优化方法，以及为何训练会发散。
- 应用研究者：为特定领域评估架构、微调策略与 RL 方法。
- Agent 开发者：编排模式、记忆架构、工具集成（MCP）、多智能体协作（A2A）。
- 系统工程师：训练基础设施、GPU 集群、分布式训练与推理部署。
- 技术负责人：在全栈层面做架构与资源决策。

前置门槛只有两条：神经网络 + 基础概率论；LLM/RL/系统知识一律不预假设。

- 主题: 三条写作原则

> 📖 **原文** (ch00 §前言·设计哲学)：1.先直觉、后形式化。每一个方程之前，都会先用通俗语言解释它的含义与重要性。

🧭 **归纳**：
1. 先直觉、后形式化——每个方程前先用日常语言解释它为什么重要。这决定了本书的读法：先读文字解释，再看公式。

3. 对「什么有效」诚实——明确标注哪些方法经生产验证、哪些仍在研究阶段。

➕ **补充**：第 3 条在正文里有可验证的落点，例如 Muon 被写明「在 LoRA 适配器、小型微调与 RL 训练上的行为则尚未被充分刻画」，因此仍推荐 AdamW（见 Q1-15）。

## Q0-6 哪些领域被有意排除？作者的理由是什么？

- 章节: ch00 §前言·范围与有意省略　（原文：[ch00](../00-原书档案/fulltext/ch00.md)）
- 主题: 范围边界

> 📖 **原文** (ch00 §前言·范围与有意省略)：本指南聚焦于文本输入、文本输出的语言模型，以及围绕它们构建的RL、系统与智能体基础设施。有几个重要领域被有意排除：

> 📖 **原文** (ch00 §前言·范围与有意省略)：•多模态模型（视觉–语言、音频、视频）。多模态架构引入了独特的训练流水线（对比预训练、跨模态对齐、模态专用编码器）、数据精选挑战与评估协议，每一项都值得用一本书的篇幅来讨论。将其纳入只会让范围翻倍，却无法加深贯穿本指南的RL与智能体核心。

> 📖 **原文** (ch00 §前言·范围与有意省略)：通过守住这条边界，我们得以保持一条连贯的主线——从架构基础与系统基础设施，到产出对齐与推理模型的训练算法，再到自主智能体的编排与部署——而不至于因穿插不同模态与垂直行业而让叙事破碎。— Haggai Roitman，2026

🧭 **归纳**：排除清单与理由：
- 多模态（视觉/音频/视频）：训练流水线与评估协议各自都值一本书，纳入只会让范围翻倍。
- 垂直领域部署（医疗、法律、金融、科学发现）：监管约束、专门评估与数据访问问题与通用方法正交。
- 个性化与推荐系统：用户建模、协同过滤、bandit 探索、冷启动构成平行的研究传统。
- 保留的主线：架构基础 → 系统基础设施 → 对齐与推理的训练算法 → 自主智能体编排与部署。

## Q0-8 通往智能体 AI 的十个里程碑有什么共同规律？

- 章节: ch00 §引言·通往智能体AI之路：一段简史　（原文：[ch00](../00-原书档案/fulltext/ch00.md)）
- 主题: 历史里程碑规律

> 📖 **原文** (ch00 §引言·通往智能体AI之路：一段简史)：9.推理模型（2024）[ 72 ]—— OpenAI的o1与DeepSeek-R1表明，仅依靠reward信号，RL就能教会模型推理：思维链、回溯与自我验证自发地涌现。模型开始攻克竞赛级数学题与复杂编码任务。

> 📖 **原文** (ch00 §引言·通往智能体AI之路：一段简史)：10.智能体AI（2025至今）——汇合点到来：具备推理能力的LLM，配上标准化工具访问（MCP）、智能体间通信（A2A）、持久化记忆与成熟的编排框架。Agent现在能够自主编写代码、开展研究、管理工作流，并与其他Agent协作——正是本指南的主题。

> 📖 **原文** (ch00 §引言·通往智能体AI之路：一段简史)：每一个里程碑都共享一条共同的轨迹：架构创新+规模+学习信号=突破。Deep Blue用的是手工搜索；AlphaGo从自我对弈中学习；GPT-3从互联网文本中学习；今天的智能体系统则从人类反馈、可验证奖励与环境交互中学习。学习信号已经从博弈胜负扩展到开放式的人类偏好——架构也随之成长以与之匹配。

🧭 **归纳**：
- 十个里程碑的共同公式：架构创新 + 规模 + 学习信号 = 突破。
- 学习信号的演变轨迹：博弈胜负（Deep Blue）→ 自我对弈（AlphaGo）→ 互联网文本（GPT-3）→ 人类反馈与可验证奖励（今天）。
- 2025 年智能体 AI 的成立条件是「汇合」：推理型 LLM + MCP 工具访问 + A2A + 持久化记忆 + 成熟编排框架。
