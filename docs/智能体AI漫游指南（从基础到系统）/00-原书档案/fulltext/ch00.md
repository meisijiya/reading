# 前言

### 为什么要写这本指南

在2026年构建智能AI系统，需要掌握极其广阔的知识——从Transformer在内部如何处理语言，到使训练成为可能的硬件与系统，再到让训练高效的优化技术、教会模型推理并与人类意图对齐的强化学习算法，乃至大规模协调自主系统的多智能体架构。这些知识散落在数百篇论文、博客文章、GitHub仓库，以及少数实验室内部的“部落知识”之中。本指南之所以存在，是因为从业者需要一份覆盖整套技术栈的统一参考——不仅是理论，更是让事情真正跑起来的实现细节。

### 我个人走向智能体AI的旅程

我对智能体（agent）的迷恋始于二十年前，那时我还在攻读信息系统工程的本科学位。我选修了面向智能体的软件工程（Agent-Oriented Software Engineering, AOSE）[ 382 ]课程，并学习如何用JADE [ 22 ]（Java Agent DEvelopment Framework）构建多智能体系统——这是一个遵循FIPA [ 93 ]标准的平台，智能体之间通过结构化协议通信、就共享资源协商，并自主协作。与此同时，Berners-Lee、Hendler与Lassila发表的奠基性论文《The Semantic Web》[ 24 ]描绘了一种机器可读知识的愿景，让智能体能够在其上推理。这两条线索——自主智能体架构与语义知识表示——种下了一颗种子，此后一直引导着我的职业生涯。一个早期项目让这一愿景具体化：在我未来尊敬的学术导师Prof. Avigdor Gal的指导下，我们尝试用OntoBuilder [ 103 ]构建一个购物智能体——一个能够在不同异构网站上自动填写商品搜索查询与订单的系统，通过本体匹配与映射来理解它们各异的schema。Semantic Web承诺，在一个结构化、机器可读的世界里，这类智能体将大放异彩。然而在实践中，手工本体的脆弱性、真实商品数据的混乱，以及缺乏稳健的自然语言理解，让这个愿景永远停留在“还有五年”。在随后的岁月里，我亲历了AI进步的每一次浪潮：用于组合优化的神经网络与启发式搜索；深度学习与表征学习；大规模信息检索与个性化；以及最近的大语言模型革命。每一波浪潮都带来强大的新工具，但梦想始终未变：构建能在复杂环境中自主理解、推理与行动的系统。2024–2026年之所以非凡，是因为这些线索终于汇合在一起。LLM提供语言理解与生成能力；强化学习教会它们推理并与人类意图对齐；工具使用协议（Model Context Protocol, MCP）赋予它们在世界中行动的“手”；智能体编排框架提供了二十年前JADE曾设想过的协作层——只是现在由基础模型驱动，而非手工编写的本体。在很多意义上，本指南正是我希望自己在那段旅程的每一步都能拥有的参考。

### 2026年的全景

通向今天智能体AI系统的旅程，横跨三十年间在架构、训练与部署上不断累积的突破：

1.架构基础（2017–2020）：Transformer [ 357 ]把self-attention引入为一种通用的序列处理原语。Scaling Laws揭示：用更多数据训练的更大模型会稳定地变好。GPT-2与GPT-3证明，仅decoder结构的Transformer在足够规模化之后，会成为有能力的few-shot learner。

2.系统与效率（2020–2023）：FlashAttention [ 65 ] 通过消除显存瓶颈让训练加速2–4 ×。LoRA [ 147 ]让在单个节点上微调70B+模型成为可能。专家混合（Mixture-of-Experts, MoE）将模型容量与算力成本解耦。vLLM这类推理引擎把吞吐量带到了实时应用可触及的范围。

3.基于RL的对齐（2022–2024）：RLHF [ 280 ]把“有能力但不实用”的base模型变成了真正有用的助手——这正是ChatGPT背后的配方。DPO [ 302 ]把reward模型与RL循环压缩成单一的监督loss，降低了对齐的门槛。变体随之涌现：KTO [ 87 ]、IPO [ 14 ]、ORPO [ 141 ]、GRPO [ 323 ]。

4.推理与自主（2024–2026）：DeepSeek-R1 [ 72 ]与OpenAI的o1/o3证明：RL可以教会模型推理本身——模型自发地发现思维链（Chain-of-Thought，CoT）、回溯与自我验证。与此同时，Model Context Protocol (MCP)统一了工具访问、智能体到智能体（Agent-to-Agent, A2A）使智能体间通信成为可能，生产级编排框架也走向成熟。

### 范围与有意省略

本指南聚焦于文本输入、文本输出的语言模型，以及围绕它们构建的RL、系统与智能体基础设施。有几个重要领域被有意排除：

•多模态模型（视觉–语言、音频、视频）。多模态架构引入了独特的训练流水线（对比预训练、跨模态对齐、模态专用编码器）、数据精选挑战与评估协议，每一项都值得用一本书的篇幅来讨论。将其纳入只会让范围翻倍，却无法加深贯穿本指南的RL与智能体核心。

•特定领域部署（医疗、法律、金融、科学发现）。领域适配带来监管约束、专门评估与数据访问问题，这些都与本文呈现的通用方法正交。我们覆盖的算法与架构正是从业者向这些领域适配时所使用的构建模块，但适配细节交由专门的参考文献会更合适。

•个性化与推荐系统。个性化依赖用户建模、协同过滤与交互历史架构，构成了一条平行的研究传统。尽管LLM越来越多地被用在推荐系统中，但其核心技术（序列模型、基于bandit的探索、冷启动处理）足够独特，值得另行讨论。

通过守住这条边界，我们得以保持一条连贯的主线——从架构基础与系统基础设施，到产出对齐与推理模型的训练算法，再到自主智能体的编排与部署——而不至于因穿插不同模态与垂直行业而让叙事破碎。— Haggai Roitman，2026

### 宏观图景

本指南将带你从第一原理走到生产系统。它面向想要理解并构建现代AI完整技术栈的从业者——研究者、工程师与应用科学家：从Transformer架构与运行它们的硬件，到使模型与人类意图对齐并教会它们推理的训练算法，再到把模型作为自主系统部署出去的智能体架构。核心论点很简单：构建优秀的AI系统需要理解整条流水线，而不仅是某一层。调试训练过程的工程师需要理解GPU显存层级与优化器动力学。做微调的从业者要知道何时LoRA已足够、何时全参数训练值得这个成本。Agent开发者需要理解底层模型是如何训练出来的。评估框架的技术负责人需要理解每个框架做出了怎样的权衡。本指南提供这幅完整的图景。

### 通往智能体AI之路：一段简史

今天的智能体AI系统并非凭空出现。它们站立在数十年间一系列里程碑式系统之上——每一个都解决了一个更窄的问题，但它们共同积累起的技术、硬件与雄心，最终让自主智能体成为可能。

1. Deep Blue（1997）[ 37 ] —— IBM的象棋引擎以暴力搜索（每秒2亿个局面）配合手工评估函数，击败了世界冠军Garry Kasparov。它证明了机器在边界清晰的对抗性领域可以超越人类，但无法泛化到其他任何任务。

2. IBM Watson —— Jeopardy!（2011）[ 90 ] —— Watson结合了信息检索、NLP与大规模并行，在开放领域问答中战胜人类冠军。它表明AI能够在规模上处理非结构化文本，但需要多年针对领域的工程，且如果没有大量人力，便无法学习新领域。

3. AlexNet与深度学习革命（2012）[ 192 ] —— Krizhevsky等人的CNN在ImageNet上以惊人的领先优势夺冠，证明了在GPU上训练的深度神经网络可以从原始数据中学到表征。仅此一个结果便引爆了现代深度学习时代，以及最终让LLM成为可能的硬件投入。

4. AlphaGo（2016）[ 331 ] —— DeepMind 的系统用深度RL（policy 网络+ value 网络+ 蒙特卡洛树搜索）击败了围棋世界冠军Lee Sedol。与Deep Blue的暴力搜索不同，AlphaGo是学会下棋的——证明了RL能够攻克仅靠搜索无法处理的领域（10 170个棋盘状态）。随后AlphaGoZero（2017）[ 332 ]完全通过自我对弈学习，根本不需要任何人类棋谱。

5. GPT-2/GPT-3（2019–2020）[ 32 ] —— OpenAI表明，把decoder-only Transformer扩展到数十亿参数会涌现出few-shot learning能力。GPT-3（175B参数）仅凭上下文示例，就能完成它从未被显式训练过的任务——翻译、算术、代码生成。基础模型的时代由此开始。

6. AlphaFold（2020）[ 174 ] —— DeepMind解决了悬而未决50年的蛋白质折叠问题，以原子级精度预测蛋白质3D结构。AlphaFold证明了深度学习能够攻克此前被认为距离我们还有数十年的根本性科学难题，同时也展示了“架构创新（在残基对上做attention）+大规模算力”组合的威力。

7. ChatGPT与RLHF（2022）[ 280 ] —— InstructGPT/ChatGPT证明：一个有能力的base模型，在经过RLHF对齐后，会变成真正有用的助手。这是一个拐点：AI从研究工具变成了被亿万用户使用的消费产品。其对齐技术（reward模型、PPO）成为此后所有LLM后训练的模板。

8. GPT-4与多模态模型（2023）[ 274 ] ——多模态能力（视觉+语言）、更长的上下文与更强的推理能力，把LLM推向通用认知。工具使用（代码解释器、浏览网页）已经初见智能体能力的端倪。

9.推理模型（2024）[ 72 ] —— OpenAI的o1与DeepSeek-R1表明，仅依靠reward信号，RL就能教会模型推理：思维链、回溯与自我验证自发地涌现。模型开始攻克竞赛级数学题与复杂编码任务。

10.智能体AI（2025至今）——汇合点到来：具备推理能力的LLM，配上标准化工具访问（MCP）、智能体间通信（A2A）、持久化记忆与成熟的编排框架。Agent现在能够自主编写代码、开展研究、管理工作流，并与其他Agent协作——正是本指南的主题。

每一个里程碑都共享一条共同的轨迹：架构创新+规模+学习信号=突破。Deep Blue用的是手工搜索；AlphaGo从自我对弈中学习；GPT-3从互联网文本中学习；今天的智能体系统则从人类反馈、可验证奖励与环境交互中学习。学习信号已经从博弈胜负扩展到开放式的人类偏好——架构也随之成长以与之匹配。

本指南从基础模型时代接续叙事，并把它推进到对齐、推理与自主智能体阶段。

### 你将看到什么

第一部分：基础（第1–3章）搭建本指南其余部分所依赖的基础知识。我们从LLM在内部如何工作开始——决定能力的架构决策——然后覆盖让训练与推理成为可能的硬件与系统，最后从第一原理引入强化学习。

•第1章—— LLM架构与优化：Transformer内部机制（self-attention、multi-head attention、RoPE、GQA）、FlashAttention、优化方法（AdamW、学习率调度、梯度裁剪）、混合精度、LoRA/QLoRA、量化、知识蒸馏与Mixture of Experts。

•第2章——系统基础：GPU架构（A100/H100/B200）、内存层级、NVLink/NVSwitch、分布式训练（FSDP、DeepSpeed ZeRO、张量/流水线并行），以及用于高吞吐推理的vLLM。

•第3 章—— RL 简介：MDP、Bellman 方程、TD 学习、Q-learning、policy gradient（REINFORCE）、actor-critic方法、GAE ——支撑第二部分的算法工具箱。

第二部分：面向LLM的RL方法（第4–12章）是训练与对齐的核心。在这里你会学到如何对齐、改进与微调语言模型——从完整的数学推导到可运行的代码。

•第4–8章：每一个主流RL /偏好算法都配有数学推导、直觉解释与TRL代码—— PPO、DPO、GRPO，以及偏好优化变体（Online DPO、KTO、IPO、ORPO、SimPO、Best-of-N）。

•第9–10章：Reward模型训练（Bradley-Terry、scaling laws、reward hacking）与SFT最佳实践（数据质量、课程学习、格式化）。

•第11–12章：大规模系统架构（解耦训练、容错、GPU分配）与LLM智能体训练——如何用轨迹级RL端到端训练Agent。

第三部分：推理（第13章）覆盖模型能力的前沿——教LLM解决多步问题。

•第13章——大型推理模型的RL：DeepSeek-R1、OpenAI o1/o3/o4-mini、QwQ —— RL如何发现思维链、MCTS、过程奖励模型与测试时算力扩展。

第四部分：评估（第14章）提供测量“上面这些是否真的有效”的方法论。

•第14章—— LLM评估：指标（perplexity、pass@k、ELO）、LLM-as-Judge模式、污染检测、基准套件，以及智能体评估方法论。

第五部分：智能体AI（第15–27章）带你从一个训练好的模型走向一个被部署出去的自主系统。这是篇幅最大的部分，覆盖了一个Agent在真实世界中运作所需的一切。

•第15章——智能体AI简介：是什么让一个系统具备“智能体性”，从聊天机器人到自主Agent的光谱，以及第五部分余下章节所需的基础概念。

•第16章—— RAG：检索方法、分块、Embedding模型、混合检索、重排，以及生产架构。

•第17章——记忆系统：用于Agent持久知识的工作记忆、情景记忆、语义记忆与程序性记忆。

•第18章——编排：ReAct、Plan-and-Execute、LLM Compiler、reflexion模式、上下文管理与harness设计。

•第19章——循环工程（Loop Engineering）：推理时强化学习、上下文工程（ContextEngineering）、自适应编排循环，以及“循环即策略”（loop-as-policy）抽象。

•第20章——设计模式：prompt chaining、路由、并行化、评估驱动的编排，以及“简洁性原则”。

•第21章——环境与基准：WebArena、SWE-bench、OSWorld、GAIA ——评估智能体能力的环境。

•第30章——总结与未来方向：领域将走向何方——开放问题、新兴范式与前路。
