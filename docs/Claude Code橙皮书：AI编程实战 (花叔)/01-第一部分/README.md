> 📖 **原文**（§1.1）：AI编程工具在3年间发生了3次重大变化。搞清楚这个演变路径，你就能理解Claude Code到底在做一件什么不一样的事。

> 📖 **原文**（§1.2）：Claude Code在2025年2月公开发布（研究预览版），同年5月正式发布。正式发布后仅6个月，年化收入就达到10亿美元。这在SaaS历史上极其罕见。

> 📖 **原文**（§1.4）：传统AI编程工具关心的是代码生产效率：怎么更快地写出一个函数、一个组件。Claude Code关心的是产品构建效率：怎么更快地将一个想法变成一个能运行的产品。

> 🧭 **归纳**：Claude Code 是 AI 编程工具的第三代范式（Copilot 补全→Cursor 改写→Claude Code 自主规划），2025 年 2 月发布后 6 个月内年化收入达 10 亿美元。它关心的不是代码生产效率（写函数/组件），而是产品构建效率（想法→可运行产品），开发者从『监工』转向『产品决策者』。

> 📖 **原文**（§3.2）：为什么选择这个项目？因为它够小，一个下午就能做完；它又够完整，涉及网络请求、数据处理、AI调用和文件输出。

> 📖 **原文**（§3.3）：很多工程师第一次用Claude Code时，本能地想看每一行代码、理解每个实现细节。这是正常反应，但这样做会降低效率。

> 📖 **原文**（§3.5）：这是最常见的问题，通常是因为依赖没有安装好，或者环境变量没有正确设置。解决方法很简单：把完整的报错信息粘贴给Claude Code。

> 🧭 **归纳**：第一个项目应选『够小但够完整』（如每日 AI 新闻聚合器）覆盖网络请求/数据处理/AI 调用/文件输出四要素。心态切换：从写代码→产品经理（只说『要什么』，不说『怎么写』）。铁律：①每模块完成后立即验证（OAuth/curl 测试/AI 总结检查）；②完整报错信息贴给 Claude Code 能解决 90% 问题。
