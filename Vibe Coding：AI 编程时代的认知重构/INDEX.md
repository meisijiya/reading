## ⚠️ 覆盖率与数据来源声明（必读）

本知识包通过微信读书 Agent API 构建。**该 API 不提供正文章节全文接口**，因此：

| 层 | 完整度 | 来源 |
|---|---|---|
| 章节目录（27条目=14正文章+前置材料+3部曲分隔页） | ✅ 100% | `/book/chapterinfo` 接口 |
| 原书文本 | ⚠️ 部分：**244条热门划线原文，约1.35万字，覆盖20/27个目录条目（14个正文章节全覆盖）** | `/book/bestbookmarks` 接口（每章按读者标记人数排序的热门划线 top~20） |
| 方法提炼（速查表） | 由上述原文归纳 + 编者补充公开常识 | 见三级标记约定 |

**证据标记约定**（全包统一）：
- 📖 **原文** = 微信读书热门划线逐字引用，未改动（括号内"X人标记"=热度可信度权重）
- 🧭 **归纳** = 编者从原文提炼的结构化结论
- ➕ **补充** = 编者依据公开常识补充（非原书内容）

**升级到100%全文的方法**：将你账号内导出的全书内容（EPUB/TXT/PDF）按章节分文件放入 `00-原书档案/fulltext/`（命名 `uid-XX-题名.md`），并更新本文件即可；其余结构无需变动。

## 目录结构与检索指南

```
Vibe Coding：AI 编程时代的认知重构/
├── INDEX.md                  ← 本文件：导航入口
├── 00-原书档案/               ← 原始数据（机器可读）
│   ├── book-meta.json            书籍元信息原样归档
│   ├── toc.json / toc.md         完整27条目目录（含 chapterUid）
│   ├── hot-highlights.json       244条划线原始JSON（uid→title+items[text,heat,range]）
│   └── fulltext/                 ← 全文升级位（当前为空）
├── 01-走近VibeCoding/README.md   导读卡(22条) + Q01-Q04（第1部分，74条）
├── 02-如何VibeCoding/README.md   Q05-Q10（第2部分，98条）
├── 03-VibeCoding的未来/README.md Q11-Q14（第3部分，50条）
├── 99-速查表.md               ← 场景→方法速查 + 关键数字（最常调用）
└── additions/                 ← 你的新理解/新案例/实践结果追加处
    └── README.md
```

**给 AI 的检索建议**：
1. 先查 `99-速查表.md` 定位场景/概念 → 再回对应模块 README 读原文证据链
2. 按 Q 编号 grep（如 `Q06`）可直接命中卡片；卡片头部含章节 UID 可回溯 `hot-highlights.json`
3. 需要精确出处时查 `hot-highlights.json` 的 `range` 字段（章节内字符偏移）；heat（标记人数）= 该观点在读者群体中的共识强度
4. 引用时严格区分 📖原文 / 🧭归纳 性质；本书观点含时效性预测（如40%自动化），引用时保留限定词
5. 用户增量认知在 `additions/`，与速查表同优先级，标注"影响"的条目覆盖旧条目
