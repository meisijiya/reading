> 🧭 **归纳**：Chrome 扩展 MV3 的 3 运行环境必须分工：background.js（指挥中心，chrome.alarms 扫描循环+消息路由）、content.js（薄壳，只读 cookie + 操作 DOM）、lib/（业务模块独立可测）。v1.0 教训=1211 行 content.js 全堆一起；v3.0 重构=7 个 lib/ 模块 + 175 行 content.js，总代码量 1211→2054 但认知负担骤降。逐模块实现+每步浏览器验证，不等所有文件写完再测试。
