# additions/ — 知识包增量区

本目录存放你后续产生的新理解、新案例、实践结果。**不要修改 `01~05` 的原文档案**（它们是证据层），新内容一律追加到这里。

## 命名规范

```
YYYY-MM-DD-主题.md        例：2026-08-30-用B6做会议纪要实战.md
```

## 记录模板

```markdown
# <标题>

- 日期：YYYY-MM-DD
- 类型：新理解 | 新案例 | 实践结果 | 修正
- 关联：uid NN 或速查表条目（如「P184 Security Review」/「4 C's」）

## 内容

<你的理解 / 案例经过与结果 / 实践中的做法>

## 对知识包的影响

<是否推翻或细化了某条既有规则？指出文件与条目，如「05-实战卷-F-J-与作者/README.md → §G.3 Agentic Workflows」>
```

## 维护约定

1. **冲突处理**：若新认知与原书规则冲突，在 additions 文件里写明理由即可，不回改原文层——保留演化历史。
2. **检索**：AI 使用本包时应把 `additions/*.md` 与 `99-速查表.md` 同优先级纳入检索，additions 中标注"影响"的新规则视为对速查表的覆盖更新。
3. **升级全文**：本包 100% 全本原文（epub 来源，覆盖度天然 100%），若日后原书修订，重新跑 `scripts/distill_epub_aiprompt.py --force` 即重生成 `00-原书档案/fulltext/`，其余结构不动。
