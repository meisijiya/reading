# Appendix D: Learning Resources

## Free Courses

- Learn Prompting (learnprompting.org) — Comprehensive, free, constantly updated.
- Anthropic’s Prompt Engineering Tutorial — Hands-on Claude guide.
- OpenAI Cookbook — Practical code examples.
- DeepLearning.AI short courses — ChatGPT prompt engineering, LangChain, etc.
- Google’s Prompt Engineering guide — Official Gemini-focused reference.

## Paid Courses

- Prompt Engineering for Developers (DeepLearning.AI)
- AI for Everyone (Coursera, Andrew Ng)
- Paid cohort-based programs on Maven and similar.

## Communities

- r/PromptEngineering, r/LocalLLaMA — Reddit communities.
- Prompt Engineering Discord
- LinkedIn — Follow major model providers and independent prompt engineers.

## Research and Deep Dives

- arXiv.org cs.CL — Daily research papers on language models.
- The Gradient, Import AI, Latent Space — Weekly newsletters.
- Lex Fridman Podcast, Dwarkesh Podcast, Latent Space Podcast — Long-form interviews with AI leaders.

## Official Model Docs (Bookmark These)

- docs.anthropic.com (Claude)
- platform.openai.com/docs (GPT, o-series)
- ai.google.dev (Gemini)
- docs.mistral.ai
- llama.com
