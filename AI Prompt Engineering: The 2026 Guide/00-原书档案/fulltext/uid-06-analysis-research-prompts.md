# Chapter 6: Analysis & Research Prompts

“AI doesn’t just create content — it transforms how you analyze data, conduct research, and make decisions. These 50 prompts turn AI into your personal analyst and research assistant.”

## Why Analysis Prompts Are Different

Analysis and research prompts are about insight extraction, not content creation.

| Content Prompt | Analysis Prompt |
| “Write about X” | “Analyze X and tell me what it means” |
| Creative output | Insightful interpretation |
| What the AI produces | What the AI discovers |

### The Analysis Prompt Framework

[Data/Context] + \[Analysis Type\] + \[Specific Focus\] + \[Output Format\]

Example:

Data: "Here's my marketing campaign data for Q1..."
Analysis Type: "Analyze the performance."
Focus: "Identify what worked and what didn't."
Output Format: "3 key insights with actionable recommendations."

## Data Analysis (10)

### 116. The Basic Summary

"Summarize this data in 3 key points. \[data\]"

### 117. The Trend Analysis

"Analyze this data for trends over time.
Identify: major trends, anomalies, predictions. \[data\]"

### 118. The Comparison Analysis

"Compare \[dataset A\] and \[dataset B\].
Highlight: similarities, differences, key takeaways. \[data\]"

### 119. The Correlation Search

"Analyze this data for correlations between variables.
List the top 5 correlations with strength and potential
explanations. \[data\]"

### 120. The Outlier Detection

"Identify outliers in this data.
For each: describe the outlier, possible causes,
recommended action. \[data\]"

### 121. The Performance Metrics

"Calculate these metrics from the data: \[list\].
Format as a table with definitions. \[data\]"

### 122. The Segment Analysis

"Break down this data by [segment: time, category, demographic].
Compare segments and identify standouts. \[data\]"

### 123. The Root Cause Analysis

"Perform a root cause analysis for \[problem\].
Use the 5 Whys technique. [data/context]"

### 124. The SWOT Analysis

"Conduct a SWOT analysis for \[subject\].
Include: Strengths, Weaknesses, Opportunities, Threats.
\[context\]"

### 125. The Gap Analysis

"Identify gaps between \[current state\] and \[desired state\].
For each: description, impact, priority. \[data\]"

## Chapter Summary

Analysis prompts transform AI from a content generator into your personal think tank and research department.

1. Always provide context and data.
2. Be specific about the analysis type.
3. Define the output format you need.
4. Ask for actionable insights, not just observations.
